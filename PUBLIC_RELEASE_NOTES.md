# Public release notes

This branch is a staging surface for a future public repository.

Included:
- solver source under `ssn/`
- XPINN research implementation under `xpinn/`
- result interface
- tests
- selected showcase figures
- minimal Docker and run entry points

Excluded from the release tree:
- literature PDFs, DJVU files, third-party paper source archives, and copied reference material
- unpublished related-work / novelty / gap analysis
- proof-development notes and research whiteboards
- generated datasets and large experiment outputs
- experiment logs and historical development artifacts
- internal roadmaps, TODOs, agent instructions, and local workflow configuration

Important: GitHub visibility is repository-wide. This branch inherits private history from `core`, so the existing private repository must not simply be switched to public. The sanitized tree should be exported into a new public repository with fresh history.
